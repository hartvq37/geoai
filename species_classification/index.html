Urban Individual Tree Species Identification from Aerial Imagery via Deep Active Learning

← Back to Home

This study develops a deep learning framework for multi-species ITDCD using aerial RGB images. It focuses on reducing annotation costs and improving generalisability through data-efficient learning techniques.

  • Evaluate supervised species classification under varying data sizes.
  • Apply FixMatch self-training to leverage unlabelled samples.
  • Use entropy-based active learning to identify informative samples.
  • Propose an integrated framework combining self-training and active learning.
